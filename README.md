# Annoyed Media – Website (dark theme)

Static, responsive homepage (desktop + mobile). No build step.

- `index.html` – the page (HTML, CSS and a little vanilla JS)
- `assets/am-logo.png` – logo

## Publish on GitHub Pages
Upload these files to the root of a repo, then Settings → Pages → Deploy from branch → `main` / root.

## Before launch
Replace the [placeholders] in the case study, testimonial and FAQ, the LOGO 01–07 partner slots,
and the sample ROI benchmarks in the `bench` object near the bottom of `index.html`.
